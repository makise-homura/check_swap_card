## check_swap_card

Проверяет макеты своп-карт в формате PSD на соответствие требованиям для "Стикерона".

### Запуск

В командной строке указываем файлы или маски файлов для проверки (только формат PSD).

*Примечание*: если ничего не указать, то ничего и не будет проверено.

Примеры:

```
    ./check_swap_card my_swap_card.psd
```

```
    ./check_swap_card *.psd
```

```
    ./check_swap_card batch1/*.psd batch2/*
```
